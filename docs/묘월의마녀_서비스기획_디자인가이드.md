# 묘월의 마녀 (Vernal Witch) — 서비스 기획 & 디자인 가이드

> 사주 × 타로 × 심리로 읽는 운명 리포트 모바일 서비스
> 본 문서는 vernalwitch.com 리뉴얼을 위한 기획·UX·디자인 가이드 통합본이다.

## 0. 작성 전제 / 리서치 한계

- **라이브 사이트 직접 분석 불가**: `vernalwitch.com` 은 자동화 접근(봇)에 대해 `403 Forbidden` 을 반환하여, 화면 단위 정밀 분석은 수행하지 못함. 따라서 본 진단은 ① 동일 카테고리(인디 사주·타로 브랜드) 통념, ② 경쟁사 공개 정보, ③ 의뢰인이 제공한 레퍼런스(게이미피케이션 멤버십 앱)와 기존 코드베이스(`Fortune` 리포트 엔진)를 근거로 한다.
- 사이트 정밀 분석이 필요하면, 화면 캡처를 공유해 주시면 화면별로 구체화한다.

## 2. 디자인 / UX 문제점 진단 (카테고리 공통)

인디 사주·타로 웹/앱에서 반복적으로 관찰되는 문제이며, 리뉴얼의 개선 타깃이다.

1. **첫인상 신뢰 부족** — 텍스트 위주, 일관성 없는 폰트/색, 결제 전 가치를 못 보여줌 → 이탈.
2. **정보 구조 혼란** — 상품(사주/타로/궁합…)이 평면 나열, 무엇부터 볼지 모름.
3. **결과의 가독성 저하** — 긴 텍스트 통짜. 시각화(차트·카드)·요약 부재.
4. **재방문 동기 없음** — 1회성 결제 후 다시 올 이유(오늘의 운세·습관·리워드) 부재.
5. **모바일 최적화 미흡** — 데스크톱 레이아웃 축소, 터치 타겟·하단 내비 부재.
6. **브랜드 자산 부재** — 마스코트/톤앤매너가 없어 기억되지 않음.

## 3. 경쟁사 분석

| 서비스 | 강점 | 약점/빈틈 | 시사점 |
| --- | --- | --- | --- |
| **점신** | 인지도 1위, 상담사 연결, 방대한 콘텐츠 | "안 맞는다" 평, 올드한 UI, 과한 결제 유도 | 신뢰감 있는 *정확도 체감*과 깔끔한 UI로 차별화 |
| **포스텔러** | 무료 콘텐츠로 진입장벽↓, 점성술 강함, 자율적 확장 | 사주 깊이 아쉬움 | "무료 맛보기 → 필요 시 확장" 흐름 채택 |
| **헬로우봇** | 챗봇 UX, 타로 맛집, 4.7점 | 과한 유료 전환 | 챗봇식 대화 + 캐릭터(마녀) 결합 여지 |
| **천명/사주천궁/운세7** | 전화·실시간 1:1 상담 | 플랫폼 의존, 비대면 즉시성↓ | 비대면 *셀프 리포트* + 가벼운 상담 보조 |
| **AI 사주(청월당·젠디·타로마법사)** | 웹툰형/AI 해석, 트렌디 | 정형화된 결과, 깊이 편차 | 캐릭터 내러티브 + 심리 결합으로 따뜻함 강화 |

**포지셔닝 결론**: *"가장 다정하고 보기 좋은 사주·타로"* — 점신의 정확도 신뢰, 포스텔러의 무료 진입, 헬로우봇의 캐릭터 친밀감을 합치되, **습관(매일 운세)·게이미피케이션·예쁜 리포트**로 재방문을 만든다.

## 4. 타깃 & 포지셔닝

- **1차 타깃**: 20–30대 여성, 자기이해·연애·진로에 관심, 인스타·MBTI 친화.
- **사용 맥락**: 출근길/자기 전, 가볍게 "오늘 어때?" → 가끔 깊은 리포트 결제.
- **포지셔닝 문장**: "점신은 무겁고, 무료앱은 가볍다. **묘월의 마녀**는 매일 다정하게 묻고, 결정적일 때 깊이 읽어준다."

## 5. 서비스 방향 & 킬러 콘텐츠

### 핵심 전략 3축
1. **습관(Daily)** — 매일 여는 이유: *오늘의 운세 + 출석체크 + 한 줄 마녀의 말*.
2. **깊이(Report)** — 사주×심리 결합 *프리미엄 리포트*(기존 엔진 활용: 캐릭터 카드~취급설명서).
3. **재미(Game)** — 출석/스탬프/등급(마법사 레벨)·쿠폰으로 리텐션.

### 킬러 콘텐츠
- **🔮 오늘의 운세 출석체크** — 매일 1회, 마녀가 카드 한 장을 뽑아 한 줄 코멘트 + 스탬프 적립.
- **📖 나의 운명 프로파일** — 사주 원국 + 오행 밸런스 + 심리 캐릭터 카드 + "취급설명서"(기존 Fortune 엔진).
- **💞 궁합 케미 리포트** — 두 사람 관계 곡선·시기별 흐름 시각화.
- **🃏 타로 한 장** — 질문→카드→마녀 해석(챗봇형).
- **🏅 마법사 등급** — 입문→견습→정식→대마녀. 스탬프로 승급, 등급별 쿠폰.

## 6. 기능 정의 (IA & 우선순위)


## 7. 화면 설계 (주요 화면)

1. **홈** — 상단 그라데이션 헤더(마녀 캐릭터 + 인사 + 등급 배지 + 포인트) → *오늘의 운세 출석 카드* → 빠른 메뉴 도크 → 서비스 9종 그리드 → 이벤트 카루셀 → 하단 탭바.
2. **오늘의 운세** — 카드 뒤집기 인터랙션 → 점수/키워드/마녀의 한 줄 → 스탬프 적립 애니메이션.
3. **리포트(사주 프로파일)** — 요약 캐릭터 카드 → 오행 레이더 → 섹션별 카드(연애/직업/건강…) (기존 리포트 엔진 연결).
4. **마법사(리워드)** — 등급 진행바(입문→대마녀) → 스탬프 보드 → 쿠폰함.
5. **MY** — 생년월일·출생시 입력(정확도 향상 유도), 결제/찜/알림.

> 하단 탭: **홈 · 운세 · (오늘의 운세 FAB) · 마법사 · MY**

## 8. 컨셉 & 디자인 스타일 가이드

### 8.1 무드
"봄밤의 다정한 마법" — 부드러운 파스텔, 둥근 형태, 소프트 3D 클레이, 은은한 반짝임. 레퍼런스의 게이미피케이션 톤(깔끔·여백·3D 오브제)을 사주·타로로 번안.

### 8.2 컬러 토큰
| 토큰 | HEX | 용도 |
| --- | --- | --- |
| `witch-violet` | `#7C6CD8` | 1차 브랜드/CTA |
| `witch-violet2` | `#A98BEE` | 그라데이션 보조 |
| `witch-mint` | `#BFE6D2` | 보조 포인트/긍정 |
| `witch-peach` | `#FAD7BE` | 강조/리워드 |

헤더 그라데이션: `#EBE4FB → #E5F1EC → #FBF7F1` (라일락→민트→크림).

### 8.3 타이포
- 디스플레이/제목: **Nanum Myeongjo**(명조, 신비·격조) — 큰 제목·등급명.
- 본문/UI: **Pretendard / Noto Sans KR** — 가독성.
- 숫자(포인트/점수): 굵게, 명조 또는 산세 볼드.

### 8.4 형태/컴포넌트
- 라운드: 카드 24px, 타일 18–20px, 버튼 pill(9999px).
- 그림자: 부드럽고 넓게(보라빛 8% 내외), 하드 섀도 금지.
- 카드: 흰 표면 + 1px 연보라 보더. 누르면 `scale(0.97)` 마이크로 인터랙션.
- 아이콘: **소프트 3D 클레이** 일러스트(파스텔), 작은 사이즈 가독성 우선.

### 8.5 캐릭터 사용 규칙
- 마스코트 `char-hero.png`(전신, 투명), `char-emblem.png`(얼굴 아바타).
- 홈 피처 카드·출석·로딩·빈 화면에서 등장. 과사용 금지(1화면 1마녀 원칙).

### 8.6 게이미피케이션 시스템
- **출석체크**: 일 1회, 5일마다 보너스 스탬프.
- **스탬프 → 등급**: 입문 마법사 → 견습 → 정식 → 대마녀. 등급별 쿠폰.
- **포인트**: 리포트 결제·출석으로 적립, 쿠폰 교환.

### 8.7 보이스 & 톤
- 마녀의 1인칭, 다정한 반말 톤("오늘은 살짝 들뜬 기운이야 🌙").
- 단정·공포 금지(운세는 협박이 아니라 응원). 선택지를 주는 화법.

## 9. 이번 구현 범위 (코드 반영)

- 브랜드 리브랜딩: **묘월의 마녀** + 마녀 캐릭터(`char-hero.png` 재생성, 투명).
- 디자인 토큰: `tailwind.config.ts` `witch-*` 팔레트 + `globals.css` `.app` 테마 개편.
- 홈 GUI: 그라데이션 헤더(캐릭터·등급·포인트) → 오늘의 운세 출석 카드 → 빠른 도크 → 서비스 그리드 → 이벤트 → 하단 탭바(운세/마법사 포함).
- 리포트(다크) 페이지는 스코프 분리 유지(영향 없음).

> 후속(P1+): 오늘의 운세 카드 인터랙션, 스탬프/등급 화면, 결제 플로우, 챗봇형 타로.
